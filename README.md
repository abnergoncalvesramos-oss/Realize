# Realize

Aplicativo mobile-first para encontrar, investigar, validar, analisar, simular, ranquear e decidir oportunidades.

## Estrutura
- Login com radar/globo
- Encontrar
- Investigar
- Validar
- Analisar
- Simular
- Ranquear
- Decidir

Base inicial criada para evoluir para integrações reais de imóveis, veículos, leilões e outras oportunidades.
